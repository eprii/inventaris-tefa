# Inventaris TEFA

Aplikasi web inventaris dan peminjaman barang Lab TEFA berbasis Laravel.

## Fitur

- Login, register, dan logout
- Dashboard statistik
- View data peminjam dari seeder
- CRUD barang
- CRUD peminjaman
- Pengurangan stok otomatis saat peminjaman dibuat
- Penambahan stok otomatis saat barang dikembalikan
- Export PDF data peminjaman
- Export Excel data peminjaman

## Teknologi

- Laravel
- MySQL
- Laravel Breeze
- DomPDF
- Laravel Excel
